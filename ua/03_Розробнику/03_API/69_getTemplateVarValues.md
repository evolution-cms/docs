###Отримання значень TV-параметрів для багатьох документів одним запитом

*Доступно з Evolution CMS 3.5.9.*

Метод читає лише вказані TV-параметри для переданого списку документів одним SQL-запитом, незалежно від кількості документів.
Використовуйте його для списків, у яких кожен елемент показує кілька TV: картки статей, ціни та артикули товарів, рейтинги тощо.
Виклик getTemplateVarOutput() для кожного документа в циклі виконує окремі запити на кожен документ (N+1).

array getTemplateVarValues(array $docIds, array $tvNames[, bool $withDefaults]);

**$docIds** - масив ідентифікаторів документів

**$tvNames** - масив TV-параметрів
масив назв
масив ідентифікаторів (якщо всі елементи числові)

**$withDefaults** - підставляти значення за замовчуванням
true - якщо значення порожнє або відсутнє, повертається значення за замовчуванням TV (default_text)
false - порожнє або відсутнє значення повертається як порожній рядок
За замовчуванням: true

*Зауваження: повертаються «сирі» значення - без застосування віджетів (на відміну від getTemplateVarOutput) і без перевірки,
чи прив'язаний TV до шаблону документа. Кожен переданий документ отримує всі знайдені TV. Якщо жоден TV не знайдено, повертається порожній масив.*

***

####Формат даних результату:

	Array (
		[111] => Array ( [price] => 19.90 [sku] => A-111 )
		[112] => Array ( [price] => 0 [sku] => )
	)

***

####Приклад

	/**Структура документів:
	-Каталог (1)
	--Ноутбуки (11)
	---Ноутбук A (111)
	---Ноутбук B (112)
	**/

	$goods = evo()->getDocumentChildren(11, 1, 0, 'id,pagetitle');
	$tvs = evo()->getTemplateVarValues(array_column($goods, 'id'), ['price', 'sku']);

	foreach ($goods as $good) {
		echo $good['pagetitle'] . ': ' . $tvs[$good['id']]['price'];
	}
	//TV усіх товарів читаються одним запитом, а не запитом на кожен товар.

Для Eloquent-колекцій документів той самий запит виконує SiteContent::tvList($docs, ['price', 'sku']) - він додає до кожного документа ключ tvs.
